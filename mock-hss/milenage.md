Key Specifications
The core specifications are publicly available from standards bodies like the 3GPP and the ETSI (European Telecommunications Standards Institute). 
TS 35.205: General document: Provides an overview of the algorithm set, security requirements, and general information.
TS 35.206: Algorithm specification: Contains the detailed, normative description of the Milenage algorithms (f1, f1*, f2, f3, f4, f5, f5*).
TS 35.207: Implementors' test data: Provides test data sets to verify correct implementation of the algorithms.
TS 35.208: Design conformance test data: Offers additional test data for conformance testing of the underlying kernel function.
